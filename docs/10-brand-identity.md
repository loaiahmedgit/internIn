# Brand Identity

Source: BrandKit.png ("internIn Brand Kit," dated 2024) and logo.png at the project root.

## Wordmark

Lowercase "internIn" — "intern" set in Deep Navy, "In" set in Primary Teal, with a distinctive dot accent hanging below the leading "i". A secondary/reverse logo (white + teal wordmark on a Deep Navy card) is used on dark backgrounds or wherever the primary logo needs higher contrast.

## Color palette

| Name | Hex | Role |
|---|---|---|
| Primary Teal | `#1BA59C` | brand accent, CTAs, the "In" in the wordmark |
| Deep Navy | `#213248` | primary text/mark color, dark backgrounds |
| Light Gray | `#F3F5F7` | background surfaces |
| Cool Gray | `#C7CDD3` | secondary UI, borders |
| White | `#FFFFFF` | base background, reverse logo text |

## Typography

Bold, confident, modern sans-serif for headings; clean and highly readable body type "for enhanced clarity across all platforms and touchpoints."

## UI element patterns shown in the brand kit

- **Button**: teal filled, e.g. "Get Started →"
- **Tag**: pill-shaped, teal dot + label, e.g. "Internship"
- **Card header**: navy header bar labeled "Opportunities" above a white card body (e.g. "Marketing Intern · Remote · Full-time")
- **Status chip**: teal dot + label, e.g. "Active"

## Brand attributes

Modern, Trusted, Ambitious, Clear, Professional (each shown with a small teal underline accent in the kit).

## Tagline

"Connecting ambition with opportunity. internIn."

## Design directive for implementation

The product must not look AI-generated, template-based, or like generic SaaS UI. Avoid: unnecessary gradients, excessive cards, giant rounded containers everywhere, random glowing effects, generic dashboard layouts, excessive icons, filler sections, meaningless animations, overcomplicated visuals.

Prefer: strong hierarchy, intentional whitespace, polished typography, restrained use of brand color (teal used sparingly as an accent, not everywhere), excellent responsive behavior, clear interaction states, consistent spacing, subtle details, production-level finish. Respect the existing navy/teal brand and the approved wordmark/logo assets; do not redesign the logo unless explicitly asked.
